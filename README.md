## Featured Projects

### [Home Credit Default Risk](https://github.com/prrrrypt/HomeCreditDefaultRisk)

**Python · SQL · DuckDB · LightGBM · SHAP · Streamlit**

Developed an end-to-end credit risk analytics pipeline using over **307,000 loan applications** and **1.7 million historical credit bureau records**.

- Engineered borrower-level financial and credit-history features using SQL and Python.
- Compared Logistic Regression and LightGBM using cross-validation and final held-out testing.
- Achieved **0.7487 test ROC-AUC** and **0.2329 Average Precision**, a **6.9% relative AP improvement** over Logistic Regression.
- Demonstrated that the highest-scoring 20% of applications contained **50.03% of observed repayment-difficulty cases**.
- Developed an interactive dashboard featuring risk segmentation, SHAP explainability, and hypothetical review-cost scenarios.

**[View Source Code](https://github.com/prrrrypt/HomeCreditDefaultRisk)** | **[Explore Live Dashboard](https://homecreditdefaultrisk.streamlit.app/)**
